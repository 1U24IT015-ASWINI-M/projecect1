# projecect1
+Project Overview

This project focuses on AI-based Stock Market Sentiment Analysis using financial news articles and historical stock market data. The goal is to analyze the sentiment expressed in news articles and classify it as Positive, Neutral, or Negative, helping investors understand how news may influence stock prices. The project combines Natural Language Processing (NLP), Machine Learning, and Deep Learning techniques to build accurate sentiment classification models.

The project begins with data preprocessing and exploratory data analysis to understand the dataset and identify patterns in stock prices and news sentiment. News articles are then converted into numerical representations using Word2Vec, BAAI/bge-base-en-v1.5, and all-MiniLM-L6-v2 Sentence Transformer embeddings. These embeddings are used to train Random Forest and Neural Network models, which are evaluated using metrics such as Accuracy, Precision, Recall, F1-Score, and Confusion Matrix to identify the best-performing model.

The final outcome of the project is an intelligent sentiment analysis system that enables investment firms and financial analysts to monitor market sentiment, generate weekly news summaries, and support more informed stock market investment decisions.
